# `nus-outlook` command reference

> Generated by `scripts/generate_skill_references.py` from the argparse tree. Do not edit manually.

Read, cache, and manage NUS Outlook mail using a saved NUS SSO browser login.

Arguments/options follow their command; global options precede it. Positional arguments are listed
in order. Unmarked arguments are optional; `-h/--help` is available everywhere.

Low-level `api` output is unfiltered response data and has no `--format` option.

## Environment variables

| Variable            | Effect                                                                        |
| ------------------- | ----------------------------------------------------------------------------- |
| `SK4N_HOME`         | Override the stable data root used to derive the service's default data path. |
| `SK4N_SESSION_DIR`  | Override the private directory containing saved browser authentication state. |
| `OUTLOOK_BASE_URL`  | Set the Microsoft Outlook mailbox URL used by --base-url.                     |
| `OUTLOOK_SITE_NAME` | Set the saved-session namespace used by --site-name.                          |
| `OUTLOOK_TIMEOUT`   | Set the request and silent login-renewal timeout in seconds.                  |

## Global options

| Argument                | Details                                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `--data-path DATA_PATH` | Local Outlook cache directory. Default: `<user-data>/sk4n/outlook`.                                                 |
| `--base-url BASE_URL`   | Advanced HTTPS mailbox URL on a supported Microsoft Outlook host. Default: `https://outlook.cloud.microsoft/mail/`. |
| `--site-name SITE_NAME` | Advanced saved-session namespace. Default: `nus_outlook`.                                                           |
| `--timeout TIMEOUT`     | Request timeout in seconds. Default: `30`.                                                                          |

Exit codes: 0 success, 1 unauthenticated status, 2 validation, 3 authentication, 4 transport, 5
remote HTTP/response failure.

## `nus-outlook auth`

Manage the saved NUS login.

Required subcommand: `status`, `login`, `logout`.

## `nus-outlook auth status`

Check the saved login.

| Argument          | Details                                                         |
| ----------------- | --------------------------------------------------------------- |
| `--format FORMAT` | Output machine-readable authentication status. Choices: `json`. |

## `nus-outlook auth login`

Open a browser for NUS login and MFA.

| Argument                      | Details                                                                                                               |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `--refresh`                   | Ignore saved authentication and perform a fresh login.                                                                |
| `--login-hint EMAIL`          | Microsoft sign-in address: `...@u.nus.edu` for students or `...@nus.edu.sg` for staff. Subsequent logins remember it. |
| `--wait-seconds WAIT_SECONDS` | Login detection timeout. Default: `300`.                                                                              |

## `nus-outlook auth logout`

Delete this CLI's saved login without signing other browsers out.

## `nus-outlook folders`

## `nus-outlook people`

Find people's email addresses in the NUS directory.

| Argument        | Details                                                                             |
| --------------- | ----------------------------------------------------------------------------------- |
| `QUERY`         | Name or email to look up, for example an instructor, tutor, or TA's name. Required. |
| `--limit LIMIT` | Maximum matches. Default: `20`.                                                     |

Also accepts [shared options](#shared-options): `--format`.

## `nus-outlook messages`

List messages without marking them read.

| Argument   | Details                                                                                   |
| ---------- | ----------------------------------------------------------------------------------------- |
| `--unread` | Only unread messages.                                                                     |
| `--body`   | Also fetch full bodies. Default: use only the list response without per-message requests. |

Also accepts [shared options](#shared-options): `--folder`, `--folder-id`, `--limit`, `--offset`,
`--refresh`, `--no-refresh`, `--attachments`, `--format`.

Default: one list request, metadata only. --body and --attachments opt into message detail requests.
Offline listing filters cached records.

## `nus-outlook search`

Search mailbox messages.

| Argument | Details                                                                                     |
| -------- | ------------------------------------------------------------------------------------------- |
| `QUERY`  | Outlook search query, for example 'subject:internship'. Required.                           |
| `--body` | Also fetch full bodies. Default: use only the search response without per-message requests. |

Also accepts [shared options](#shared-options): `--folder`, `--folder-id`, `--limit`, `--offset`,
`--refresh`, `--no-refresh`, `--attachments`, `--format`.

Default: one search request, without per-message fetching. Queries are not cached. Offline search is
unsupported; use messages --no-refresh --format json with jq or grep.

## `nus-outlook message`

Read one message without changing its read state.

| Argument     | Details                                              |
| ------------ | ---------------------------------------------------- |
| `MESSAGE_ID` | Message ID returned by messages or search. Required. |

Also accepts [shared options](#shared-options): `--refresh`, `--no-refresh`, `--attachments`,
`--format`.

## `nus-outlook preview`

Capture an Outlook web screenshot of a draft or message without changing mail.

| Argument          | Details                                                                                                      |
| ----------------- | ------------------------------------------------------------------------------------------------------------ |
| `MESSAGE_ID`      | Exact draft or message ID. Required.                                                                         |
| `--output OUTPUT` | Export a copy to this PNG path. The preview is always cached as preview.png beside the email's message.json. |

Also accepts [shared options](#shared-options): `--refresh`, `--no-refresh`, `--format`.

Reuses a cached screenshot when the message is unchanged. --refresh forces recapture; --no-refresh
requires a valid local preview. Screenshots show the viewport; read the returned body for long
messages.

## `nus-outlook draft`

Create, edit, discard, or send an existing draft with user authorization.

Required subcommand: `create`, `reply`, `edit`, `send`, `remove`.

## `nus-outlook draft create`

Save a new unsent message.

| Argument            | Details                  |
| ------------------- | ------------------------ |
| `--subject SUBJECT` | Draft subject. Required. |

Also accepts [shared options](#shared-options): `--to`, `--cc`, `--bcc`, `--body`, `--body-file`,
`--attach`, `--format`.

## `nus-outlook draft reply`

Save an unsent reply to one message.

| Argument     | Details                        |
| ------------ | ------------------------------ |
| `MESSAGE_ID` | Original message ID. Required. |

Also accepts [shared options](#shared-options): `--body`, `--body-file`, `--attach`, `--format`.

## `nus-outlook draft edit`

Edit specified draft fields and/or add attachments; save without sending.

| Argument            | Details                      |
| ------------------- | ---------------------------- |
| `MESSAGE_ID`        | Existing draft ID. Required. |
| `--clear-to`        | Remove all To recipients.    |
| `--clear-cc`        | Remove all Cc recipients.    |
| `--clear-bcc`       | Remove all Bcc recipients.   |
| `--subject SUBJECT` | Replace the subject.         |

Also accepts [shared options](#shared-options): `--to`, `--cc`, `--bcc`, `--body`, `--body-file`,
`--attach`, `--format`.

- Mutually exclusive: `--to` / `--clear-to`.
- Mutually exclusive: `--cc` / `--clear-cc`.
- Mutually exclusive: `--bcc` / `--clear-bcc`.
- Mutually exclusive: `--body` / `--body-file`.

## `nus-outlook draft send`

Send an existing draft only, saving a copy in Sent Items.

| Argument     | Details                                                       |
| ------------ | ------------------------------------------------------------- |
| `MESSAGE_ID` | Existing draft ID; non-draft messages are rejected. Required. |

Also accepts [shared options](#shared-options): `--format`.

Requires user authorization. Review the draft and its preview first; present its link and preview
for approval unless the user explicitly waived their review. Never retry an uncertain send without
checking Sent Items.

## `nus-outlook draft remove`

Discard a draft into Deleted Items.

| Argument     | Details                     |
| ------------ | --------------------------- |
| `MESSAGE_ID` | Draft message ID. Required. |

Also accepts [shared options](#shared-options): `--format`.

## `nus-outlook api`

Make a read-only Outlook web API request.

| Argument              | Details                                                                                                                      |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `PATH`                | Supported /owa/service.svc read action, /searchservice/api/v2/query (mail), or /search/api/v2/query (people) path. Required. |
| `-X, --method METHOD` | HTTP method. Default: GET. POST is limited to supported read actions. Choices: `GET`, `POST`.                                |
| `-d, --data JSON`     | JSON request body.                                                                                                           |

- Only /owa/service.svc with a supported read action, POST /searchservice/api/v2/query (mail), or
  POST /search/api/v2/query (people) is accepted; state-changing actions are rejected.

Open an authenticated @playwright/cli inspection session.
