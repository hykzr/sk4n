# `nus-outlook` command reference

> Generated by `scripts/generate_skill_references.py` from the argparse tree. Do not edit manually.

Read, cache, and manage NUS Outlook mail using a saved NUS SSO browser login.

## Output formats

- Omit `--format` for concise human-readable tables or details.
- Use `--format json` for one compact JSON document containing useful fields.
- Use `--format jsonl` for the same compact detail, one record per line when the command offers it.
- Use `--format json-full` for full records, including fields omitted by compact output. Some
  compact endpoints offer only json.
- Use `--format plain` for line-oriented `key: value` records suited to shell filtering when the
  command offers it.
- Compact formats include useful content and state; json-full includes full records and metadata.
- Low-level api commands output response data without field filtering and do not accept --format.

## `nus-outlook draft remove`

Discard a draft into Deleted Items.

Usage: `nus-outlook draft remove [-h] [--format {json,json-full,jsonl,plain}] message_id`

| Argument          | Required | Repeatable | Default | Choices                       | Description                                                                                                          |
| ----------------- | -------- | ---------- | ------- | ----------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `-h, --help`      | no       | no         | `—`     | —                             | show this help message and exit                                                                                      |
| `MESSAGE_ID`      | yes      | no         | `—`     | —                             | Draft message ID.                                                                                                    |
| `--format FORMAT` | no       | no         | `—`     | json, json-full, jsonl, plain | Output format: json/jsonl contain useful fields; json-full includes the full record. Default: human-friendly output. |

## `nus-outlook api`

Make a read-only Outlook web API request.

Usage: `nus-outlook api [-h] [-X {GET,POST}] [-d JSON] path`

| Argument              | Required | Repeatable | Default | Choices   | Description                                                                                                        |
| --------------------- | -------- | ---------- | ------- | --------- | ------------------------------------------------------------------------------------------------------------------ |
| `-h, --help`          | no       | no         | `—`     | —         | show this help message and exit                                                                                    |
| `PATH`                | yes      | no         | `—`     | —         | Supported /owa/service.svc read action, /searchservice/api/v2/query (mail), or /search/api/v2/query (people) path. |
| `-X, --method METHOD` | no       | no         | `GET`   | GET, POST | HTTP method. Default: GET. POST is limited to supported read actions.                                              |
| `-d, --data JSON`     | no       | no         | `—`     | —         | JSON request body.                                                                                                 |

Constraints:

- Only /owa/service.svc with a supported read action, POST /searchservice/api/v2/query (mail), or
  POST /search/api/v2/query (people) is accepted; state-changing actions are rejected.
- Use the named high-level commands for authorized mail changes. The low-level api command remains
  read-only; sending requires an existing draft via draft send.

## `nus-outlook playwright-cli`

Open an authenticated @playwright/cli inspection session.

Usage: `nus-outlook playwright-cli [-h] [--url URL] [--headed | --headless] [-s SESSION]`

| Argument                | Required | Repeatable | Default       | Choices | Description                                       |
| ----------------------- | -------- | ---------- | ------------- | ------- | ------------------------------------------------- |
| `-h, --help`            | no       | no         | `—`           | —       | show this help message and exit                   |
| `--url URL`             | no       | no         | `—`           | —       | Initial Outlook URL. Default: mailbox.            |
| `--headed`              | no       | no         | `false`       | —       | Show the browser window.                          |
| `--headless`            | no       | no         | `false`       | —       | Run headless (default).                           |
| `-s, --session SESSION` | no       | no         | `nus-outlook` | —       | @playwright/cli session ID. Default: nus-outlook. |

Constraints:

- Mutually exclusive: `--headed` / `--headless`.
