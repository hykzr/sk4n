# `canvas` command reference

> Generated by `scripts/generate_skill_references.py` from the argparse tree. Do not edit manually.

Query and incrementally cache NUS Canvas data.

## Output formats

- Omit `--format` for concise human-readable tables or details.
- Use `--format json` for one complete JSON document.
- Use `--format jsonl` for one complete JSON record per line when the command offers it.
- Use `--format plain` for line-oriented `key: value` records suited to shell filtering when the command offers it.
- Structured formats preserve full records and may be substantially larger than human output.

## Environment variables

| Variable | Effect |
| --- | --- |
| `AGENT_FOR_NUS_HOME` | Override the stable data root used to derive the service's default data path. |
| `AGENT_FOR_NUS_SESSION_DIR` | Override the private directory containing saved browser authentication state. |
| `CANVAS_BASE_URL` | Set the Canvas origin used by the global --base-url option. |
| `CANVAS_SITE_NAME` | Set the saved-session namespace used by --site-name. |
| `CANVAS_TIMEOUT` | Set the default HTTP timeout in seconds. |
| `CANVAS_LOGIN_WAIT_SECONDS` | Set the default maximum wait for interactive login detection. |

## Commands

- `canvas auth` — Manage the saved NUS Canvas login.
- `canvas auth status` — Check the saved login.
- `canvas auth login` — Open a browser for NUS login.
- `canvas auth logout` — Delete the CLI's saved session without signing other browsers out of NUS SSO.
- `canvas sync` — Sync courses using the original bulk options.
- `canvas student` — Show the current Canvas student.
- `canvas list` — List accessible Canvas courses.
- `canvas course` — Show a course or one cached content area.
- `canvas api` — Send a direct low-level request with the saved Canvas session.
- `canvas playwright-cli` — Open an authenticated low-level @playwright/cli browser session.
